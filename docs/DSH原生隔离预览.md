# DSH 原生界面隔离验证

当前验证使用项目固定的 DSH 0.2.2-rc.2、临时 `DSH_HOME`、本机随机端口，且不传入已配置的 DeepSeek API 密钥或访问正式项目数据。原生 Web 服务曾在该环境中启动；通过其一次性本机授权入口验证 HTTP 响应，并在结束后清理临时数据。

验证时使用的服务参数为 `web --no-open --host 127.0.0.1 --port 0`。启动信息中的一次性本机授权链接包含临时凭据，不应复制到对话、提交记录或日志。

Playwright 已取得 800×600 窗口下的页面快照，但尚未完成对快照内容的核验，也未完成设置面板、实际浏览器缩放和高 DPI 组合的验收。一次自动安装 LabWeave 原型插件的尝试超过 120 秒；此前单独隔离测试曾安装并显示该原型。因此，目前尚不能宣称存在稳定的一键预览或正式的 DSH 主界面启动入口。

在隔离配置中，`--patch` 可接受插件的本地绝对路径并通过配置导出；但同一补丁下 Web 启动在 95 秒内未返回可用地址，尚未证明浏览器插件加载或完整启动无需网络。

这类临时 DSH 目录并不是文件系统沙箱，也不代表正式设置、项目或会话已接入。后续应先验证插件安装、认证边界、用户配置隔离和数据映射，再实现统一启动入口；具体路线见 [DSH 前端适配路线](DSH前端适配路线.md)。
