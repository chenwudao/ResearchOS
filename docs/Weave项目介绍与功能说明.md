# Weave 使用指南

Weave 是本地优先的通用项目工作区。你可以用同一套对话、资料、Bot 和任务安排产品规划、知识整理、软件开发或数据分析。科研是主要落地场景，包含文献、证据关系与实验反馈。

启动方式、模型配置和架构见 [README](../README.md)。

## 开始一个项目

1. 点击左侧「工作区」旁的加号，为项目填写名称并按需关联本机来源目录。关联文件留在原路径，可以通过项目的只读来源入口访问。
2. 点击项目「聊天」打开原生会话草稿，发送首条消息后即可在项目历史中找到它。顶部「新对话」创建全局助手会话。
3. 点击项目行的「＋」添加功能 Bot。选择目标、笔记、思维导图、点子、工程台或已有的项目扩展范式，再填写名字。项目名称和功能名称可随时更新，原记录继续使用。
4. 在项目对话中描述想要的结果及验收方式。已有资料的查询由主对话处理，需要交付的执行任务由项目主对话协调分派。

例如，产品项目可以让笔记 Bot 按主题整理客户反馈，再由目标 Bot 维护可验证的改进项。软件项目可以关联代码目录，让思维导图 Bot 整理模块依赖，工程台 Bot 在获准后运行检查并保存日志。

## 对话、分派和跟进

| 操作 | 位置与行为 |
| --- | --- |
| 全局管理 | 左上角打开助手，点击头像访问活动、审核、人设和全局记忆。转交工作时指定目标项目，是否需要确认取决于助手权限。 |
| 引用或邀请 | 在输入框键入 `@`。候选按对话作用域区分发言者、历史会话和项目资料。项目内也可引用文件和任务，宿主会再次核验归属。 |
| 发起指令 | 输入 `/` 浏览当前入口支持的动作。导航项打开对应页面，需要执行的指令进入输入草稿。 |
| 答复澄清 | 科研任务涉及范围或阶段决策时，在原生提问卡中选择或填写意见。项目对话可继续按已确认范围推进。 |
| 查看分派 | 从项目对话顶部打开「项目任务」，查看执行 Bot、进度、阻塞原因和交付。已归档 Bot 的成果仍可从项目回查。 |
| 跟进任务 | 在 Bot 对话的分派记录中选择「跟进任务」，补充内容会回到原发起对话，并关联原分派。 |
| 撤回消息 | 从消息旁的操作入口撤回。撤回提问将文字放回草稿，撤回答复保留提问。撤回位置之后的消息退出当前模型上下文。 |

侧栏蓝点表示进行中，绿点表示有未查看的完成状态，红点表示失败。完成提示可从右下角打开对应会话。Bot 对话中的执行过程可以展开查看，正文侧重发现、动作和成果。

## 用画布与资料记录结果

每个 Bot 的画布采用其范式的主排布。用户可以添加内容节点、从现有节点添加分支或删除节点。箭头表示分支与前置依赖，虚线表示普通关联。已有项目资料或文件可以从卡片来源追溯。工程台实验卡片从画布移除后，已有运行记录和文件仍可查阅。

卡片详情支持文字、图片、链接、文件和交互图表。具有可用数值列的 CSV 或 TSV 可生成折线、柱状或散点图。工程台使用已保存的指标或数据产物绘制运行曲线。草稿标为待核验，审核后可以形成正式成果。

项目主对话的「工具」打开右侧栏。空间存储按时间显示项目文件和交付物，Git 展示已识别仓库的分支、变更和最近提交。终端、浏览器与文件面板遵循当前会话配置。导入文件、来源关联和生成文件是不同记录，关闭或归档对话后仍能在项目中追溯成果。

## 以科研项目为例

1. 将公开论文、本机 PDF、代码仓库或数据作为来源。论文搜索支持 Crossref、OpenAlex、arXiv 和 Europe PMC。引用邻居和 DOI 参考文献是不同查询，结果覆盖取决于来源索引。
2. 用笔记摘录可复查出处，在导图建立证据关系。从证据缺口提出可验证的点子，为选定方向建立目标，明确范围、指标和验收方式。
3. 在项目对话中确认推进范围，安排工程台在当前权限内运行。用工程台检查实际状态、日志、指标和产物。图表来自实际记录的数据。
4. 核查结论和适用范围，更新相应的目标、点子或证据关系。将已确认的决定与项目规则保存到项目记忆。需要改变方向或扩大实际运行范围时，在提问卡中确认。

早期版本保留的动态、点子、目标和资源库仍用于各自项目。动态可订阅论文、新闻和仓库，资源库可用于导入资料、逐页阅读 PDF、对比论文和查找相关记录。扫描件需要先获得可提取文本。

## 自动化、项目指令与数据

原生「定时任务」默认选择全局助手，可以显式指定项目或绑定现有会话。动态订阅和项目复盘依赖本机服务运行。通过「更多 → 创建项目插件」可保存一段复用指令，点击后填入当前对话草稿。

项目数据库和文件在 `demo/.local`，原生会话和网页设置保存在按数据目录区分的用户 profile。停止服务后使用 `--backup`，再按需使用 `--restore <备份.zip>`。带原生会话的备份应恢复到原数据目录，详细路径和使用边界见 [README](../README.md#数据访问与备份)。
